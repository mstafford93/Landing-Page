# Portfolio Landing Page

## Overview

A created landing page that is responsive for different viewports. That advertises myself and to get viewer to further engage with the page.

## Features

- Responsive design for different view ports
- Hover effects on nav, buttons and selfie image. To improve user exerience.
- Dropdown menu when viewed on smaller viewports

## Technologies

 - HTML5 for page structure
 - CSS3 for styling, and responsive viewports
 - JavaScript for dropdown menu interaction

## Installation
Clone the repository:

git clone https://github.com/mstafford93/Landing-Page
Navigate to the project directory:

cd Landing-Page
Open index.html in your browser.

No package installation is required.
